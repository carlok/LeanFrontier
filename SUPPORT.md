# Support and contact

Use GitHub issues for public questions about installation, using the library,
the submission contract, and receiver diagnostics.

For a conduct concern, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). For a
security report, see [SECURITY.md](SECURITY.md) and use [private vulnerability
reporting](https://github.com/carlok/LeanFrontier/security/advisories/new) — do
not use a public issue.

LeanFrontier is an experimental volunteer-maintained project. No response-time
guarantee is implied.
